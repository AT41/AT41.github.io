OpenRCT2 Stat Requirement Checklist

An OpenRCT2 plugin that shows the stat requirements for the ride I'm currently building — so players can stay in the game instead of tabbing out to look things up.

info Background

Why I built this

I'm a casual OpenRCT2 player, not someone who has every ride's requirements memorized. When I build in a scenario, I only care about the rides I can actually construct, but I kept running into the same problem: I couldn't find a plugin that showed requirements scoped to what's available in my current park.

The closest thing I found was jacknull1991's Ride Requirement Plugin, which lists requirements for every possible ride in the game. That's useful as a reference, but I only want to see what rides are available to me in the current scenario, and I had to open this dialog every time I started constructing a ride.

I wanted something that followed me — open the ride I'm editing, see its requirements immediately, and move on.

What it does

The plugin opens a small window showing minimum and maximum stat requirements for whichever ride I'm currently creating, editing, or previewing, and it does it automatically through listening to game events, specifically when a user tries to modify an existing ride. It can track the ride under construction automatically, and I'm working on a checklist that marks off requirements as they're met. I published it on the OpenRCT2 plugin directory so other players who hit the same annoyance don't have to build their own.

tune Plugin Options

Settings I added so the window stays helpful without getting in the way

Open When Creating or Editing Ride

I use this as the default. When I start a new ride or open an existing one for editing, the requirements window appears on its own. If I close it, it stays closed for that ride until I switch to a different one — I didn't want it nagging me once I'd already seen the stats.

Open When Selecting Ride Preview

Handy when I'm browsing saved track designs and want to know whether a layout will pass stat checks before I commit to building it.

Change Ride Automatically

This is the option I cared about most. While a ride is under construction, the window follows whichever ride I'm working on instead of making me re-open or re-search every time I switch focus.

Close When Deleting Ride

Small quality-of-life detail — if I demolish the ride the window was tracking, the window closes instead of showing stale requirements for a ride that no longer exists.

Show Requirement Checklist

An experimental checklist that ticks off requirements as they're fulfilled. Still a work in progress, but it's the direction I want to take this — less "here are the numbers" and more "here's what you still need to hit."

lightbulb What I'd like to add next

Features I'm still thinking about for future releases

Live requirement checklist

Right now the checklist is rough. I'd like it to update in real time as I test the ride — green checkmarks for stats that pass, clear indicators for what's still missing.

Excitement / intensity / nausea breakdown

Meeting stat requirements often comes down to balancing excitement, intensity, and nausea. A breakdown showing how each stat contributes would make it easier to diagnose why a ride is failing without guesswork.
